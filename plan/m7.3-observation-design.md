# M7.3 design — the C ABI observation/debug surface

Mirrors the engine's E§8 **pull** observation API (already on `Instance`, already
surfaced by `doodle-wasm`) into `extern "C"` functions, under the M7.1 freeze
conventions (D-M7-3/§6/§7). Four ABI-shape decisions were ratified (user,
2026-09-03) — **D-M7-12..15** below — with riders that are normative for the
implementation and the M7 spec text. Everything else is a mechanical mirror:
copy-out strings (D-M7-6), count+index enumeration, `DoodleStatus` + out-params,
`catch()` at every boundary, host-owned handles the host releases, dedicated
`#[repr(C)]`/`#[repr(u32)]` mirror types owned in `abi.rs` (append-only).

## Ratified decisions

### D-M7-12 — Frame addressing: innermost-0 **index + a pause-generation token**, stale = a distinct benign status

Frames are an indexed sequence (innermost = 0); a `count` + indexed accessors is
idiomatic C iteration, allocation-free, and matches the wasm facade's `pause_gen`
model (one cross-surface vocabulary). The engine has **no** generation counter —
the C wrapper adds one to `DoodleInstance` (as the wasm facade did).

- **One token for every pause-scoped read** — frames, locals, dynamics, the
  module-globals accessor (M6.9b), tail-elided history, frame-callable — returned
  by the stack walk and **validated by every accessor**. No per-surface tokens.
- **What bumps it:** any *state-advancing* drive — `drive` / `resolve` /
  `resolve_import` / `cancel` — **but NOT auxiliary evaluation** (`eval_to_string`
  restores the paused stack, S-22), so frame addressing stays valid across an aux
  eval and reads afterward truthfully reflect its effects.
- **Check the generation BEFORE bounds:** a stale generation whose index is out of
  range for the *new* stack reports **stale**, not index-out-of-bounds.
- **A stale read is benign, expected operation, not a host bug.** Panels refresh
  asynchronously; a queued read lands after a resume. The correct host response is
  "drop it and re-walk," silently. So it gets its **own** status —
  `DoodleStatus::ErrStale` (= 13, in the initial frozen header; pre-freeze, no
  growth event) — **never** `ErrContract`, which stays reserved for host bugs
  (the S-16/S-46 family a host should assert / page on). Distinct from
  `ErrStaleHandle` (a released/forged *handle*); `ErrStale` is a stale *(gen,
  index)* addressing token.
- **Active in release** (like the cross-instance guard, D-M7-5): a stale index
  resolved against the new stack isn't *unsafe*, but hands a debugger
  wrong-but-plausible frame data — the worst failure mode for a debugging surface.
- **Parity rider:** align the wasm facade's stale error to the same vocabulary (a
  distinguishable stale error, not a generic throw), so the three-surface parity
  story includes how staleness reports.

### D-M7-13 — Frame callable: a **lazily-minted host-owned handle**, not a struct

The callable readers already exist and are frozen (`doodle_callable_name` /
`_is_function` / `_position` / `_docstring`, copy-out per D-M7-6). A parallel
reflection struct would be a *second* frozen way to read the same facts, drifting
as reflection grows (a by-value struct can't grow without the reserved-tail dance;
the reader set grows by adding a function), and a struct carrying `const uint8_t*
name` reopens the validity-window hazard D-M7-6 closed.

- The stack walk returns **pure data**: call-site position, tail count, a
  **has-callable** flag (`ModuleTopLevel` frames have none). No callable in the
  walk struct.
- `doodle_frame_callable(inst, gen, index, *out handle)` **mints on demand** [host
  -owned], gated by the pause generation like locals/globals. Inspect it with the
  existing `doodle_callable_*` readers.
- **Pin 1 — the gen scopes the *(gen, index)* addressing, not the handle.** Once
  minted, the callable handle is an ordinary host-owned handle (roots the interned
  `CalObj`, valid across resumes, released like any handle). Only the addressing
  goes stale — so hosts must not re-mint per pause out of caution.
- **Pin 2 — an absent callable is a clean result, not an error:** the walk's
  has-callable flag says so, and the accessor returns `Ok` with
  `DOODLE_NULL_HANDLE` (never a live handle) for a top-level frame. Routine.
- **Parity:** wasm parity is *conceptual, not structural* — JS gets plain objects
  (it has a GC), C gets handles + readers (its grammar). Same field vocabulary
  (pin it in the `.d.ts` ↔ `doodle.h` docs). The M7.5d trace schema is unaffected
  (renders structurally, excludes handles).

### D-M7-14 — `Position.module` is an **opaque, instance-scoped module token**

`DoodlePosition = { span_start: u32, span_end: u32, module: u32 }`, a small
by-value struct that crosses constantly (every pause, every frame's call site,
every diagnostic). Embedding a `(ptr, len)` canonical-id string in it would reopen
the ownership/validity hazard D-M7-6 closed or force a copy-out per position on a
hot path — strings don't belong in hot little structs.

- The `module` field is an **opaque instance-scoped token**, *not* a documented
  index: equal tokens ⇔ same module within one instance, stable for the instance's
  lifetime — and **nothing more**. Do not promise load-order numbering or
  cross-instance meaning (deterministic today, but kept internal in spirit). Its
  M9b-reload behavior (same canonical → same token?) is deferred to **S-24**, not
  decided here.
- `doodle_module_canonical_id(inst, module_token, buf, cap, *needed)` — copy-out
  (D-M7-6) — resolves a token to the host's canonical id. An IDE caches
  token→canonical on first sight, then every subsequent position renders for free.
- **The asymmetry is intentional:** host→engine addressing stays by **canonical
  string** (stable identity across edits/runs, S-21, unchanged); engine→host
  reporting is a cheap **token + accessor**. One sentence in the embedder README.
- **M7.5d rider:** the trace schema uses canonical ids, never tokens — add module
  tokens to the exclusion list beside handle ids and foreign pointers.

### D-M7-15 — Include the S-63 load/exec-diagnostics pull accessor in M7.3

Complete the E§8 pull surface now: `doodle_diagnostic_count(inst, since,
*out_count)` + `doodle_diagnostic_at(inst, since, index, *out_severity,
*out_position, msg_buf, cap, *out_len)`. Wraps `Instance::load_diagnostics(since)`.
Needs a `#[repr(u32)] DoodleSeverity` mirror.

## New ABI types (all in `abi.rs`, append-only)

- `DoodleStatus::ErrStale = 13` (append after `ErrPanic = 12`).
- `#[repr(C)] DoodlePosition { span_start: u32, span_end: u32, module: u32 }` — the
  opaque module token in `module`. A `has`-position is reported by the accessor's
  status/out-flag (a bare struct can't be `Option`), e.g. `*out_has: bool`.
- `#[repr(C)] DoodleFrame { has_callable: bool, has_call_site: bool, call_site:
  DoodlePosition, tail_count: u64, module: u32, reserved: [u64; 4] }` — pure data;
  the callable is minted separately (D-M7-13).
- `#[repr(u32)] DoodleGlobalKind` — mirror of `resolve::GlobalKind` (8: `Let /
  Const / Parameter / Proc / Fn / Record / Protocol / Module`).
- `#[repr(u32)] DoodleAuxOutcomeKind { Rendered = 0, Raised = 1, Faulted = 2 }`
  + `#[repr(C)] DoodleAuxOutcome { kind, value: DoodleHandle, fault: DoodleFault,
  reserved: [u64; 2] }` (follows the `DoodleOutcome` struct precedent).
- `#[repr(u32)] DoodleSeverity` — mirror of `diag::Severity`.
- (Reuse existing `DoodleObservationMode`, `DoodleKind`, `DoodleStatus`,
  `DoodleHandle`, `copy_out`/`write_out`/`read`/`catch`.)

Frame/global small structs carry a **reserved tail** (like `DoodleOutcome`); the
variable-length **name** always copies out separately (never a pointer in a struct).

## Chunk breakdown (each: implement → gates → land → CI)

- **M7.3a — pause-generation core + stack/positions/result.** Add the generation
  counter to `DoodleInstance` (bump on drive/resolve/resolve_import/cancel, not on
  eval); `doodle_current_position`/`_completed_position`/`_current_result` [HO];
  `doodle_stack_frame_count` (returns the current generation) + `doodle_frame_at`
  (fills `DoodleFrame`, gen-checked) + `doodle_frame_callable` [HO];
  `doodle_module_canonical_id`. **Also close the deferred item:** `fill_outcome`
  populates `DoodleOutcome::value` on `Completed` via `result_handle`. New:
  `ErrStale`, `DoodlePosition`, `DoodleFrame`.
- **M7.3b — frame bindings + module globals.** `doodle_frame_local_count` /
  `_local_name` (copy-out) / `_local_value` [HO]; the dynamic-params trio;
  `doodle_module_global_count` / `_global` (fills a small `{kind, slot, decl_span}`
  struct) + `_global_name` (copy-out) / `_global_value` [HO]. New:
  `DoodleGlobalKind`. All gen-checked.
- **M7.3c — structural value inspection + aux eval.** Record/dict/list/callable/
  type/module-member readers (mostly mechanical, on `*DoodleInstance`, NOT the
  `DoodleCallCtx` `doodle_call_list_*` — distinct names); `doodle_eval_to_string`
  → `DoodleAuxOutcome`. New: `DoodleAuxOutcomeKind`/`DoodleAuxOutcome`.
- **M7.3d — debug setup + tail history + diagnostics.** `doodle_set_breakpoint` /
  `_clear_breakpoint` / breakpoint list; `doodle_set_raise_trapping` /
  `_raise_trapping` / `_trapped_raise` [HO] / `_trapped_raise_position`;
  `doodle_set_observation_mode` (runtime) / `_observation_mode`; `doodle_pause`
  (mirror `doodle_cancel` — atomic, cross-thread; a standalone `PauseToken` is a
  M7.6 cross-thread question for pause **and** cancel together, not split here);
  tail-elided history (count + per-entry callable [HO] + decl-span, gen-checked);
  `doodle_diagnostic_count` / `_diagnostic_at` (D-M7-15). New: `DoodleSeverity`.
- **M7.3e — parity + review.** Align the wasm facade's stale error to `ErrStale`'s
  vocabulary (D-M7-12 rider; wasm already throws a distinct `StaleGeneration` —
  confirm/normalize naming, no behavior change); extend the C smoke with a
  paused-stack walk; a read-only handle-discipline review (host-owned handles all
  released; no handle id / raw foreign ptr / module token leaks into rendered
  output). Regenerate `doodle.h`; three-surface parity is exercised in M7.5.
